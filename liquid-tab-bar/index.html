Liquid tab barBETA

A floating glass tab bar for the web and Flutter. It has a spring lens you can drag, and it shrinks into a small pill when you scroll.

View on GitHub Try it ↓

Try it

The bar at the bottom of this page is the real component. Drag across it to move the lens, scroll down to shrink it into a pill, scroll up or tap the pill to bring it back.

What it does

Spring lens

The highlight springs to the tapped tab with a small pop, like the iOS 26 tab bar.

Drag the lens

It lifts out of the bar, stretches with your speed, and rubber-bands at the ends.

Scroll to shrink

After 66 px of scroll the bar fades into a pill showing the current tab.

Light on phones

Only transform and opacity are animated, and the loop stops when everything is at rest.

Use it on the web

<link rel="stylesheet" href="liquid-tab-bar.css">

<div class="ltb-wrap">
  <nav class="ltb">
    <a href="#home"><svg …/><span>Home</span></a>
    <a href="#me"><svg …/><span>Me</span></a>
  </nav>
</div>

<script src="liquid-tab-bar.js"></script>
<script>
  new LiquidTabBar(document.querySelector(".ltb"), {
    onChange: (index, link) => console.log(index)
  });
</script>

No dependencies. Colours are CSS variables: --ltb-accent, --ltb-ink, --ltb-bg, --ltb-lens.

Use it in Flutter

final bar = LiquidTabBarController();

NotificationListener<ScrollNotification>(
  onNotification: bar.handleScroll,
  child: ListView(…),
);

LiquidTabBar(
  controller: bar,
  selectedIndex: tab,
  onChanged: (i) => setState(() => tab = i),
  items: const [
    LiquidTabItem(icon: Icons.home_rounded, label: 'Home'),
    LiquidTabItem(icon: Icons.person_rounded, label: 'Me'),
  ],
);

Works on iOS, Android and Flutter web.

Status and limits

Web versionBeta. Tested in a browser; may still have rough edges.
Flutter versionBeta. Written without a Flutter SDK, not compiled or run yet.
LookAn imitation of the iOS 26 style, not Apple's real Liquid Glass. For the native control use adaptive_platform_ui.
PerformanceBackdrop blur is heavy on low-end Android; use a solid translucent colour there.
